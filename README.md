# Dev Container Feature: netselect

A [dev container Feature](https://containers.dev/implementors/features/) that points apt at a nearby mirror while the image is built.

- **Debian:** `netselect-apt` picks the lowest-latency mirror.
- **Ubuntu:** apt's built-in `mirror://mirrors.ubuntu.com/mirrors.txt` method.
- **Either:** or a mirror/cache URL you choose via the `mirror` option.

```jsonc
{
    "image": "mcr.microsoft.com/devcontainers/base:debian",
    "features": {
        "ghcr.io/hastarin/devcontainers-feature-netselect/netselect:2": {
            "country": "au"
        }
    },
    // Install first so every later Feature uses the mirror.
    "overrideFeatureInstallOrder": [
        "ghcr.io/hastarin/devcontainers-feature-netselect/netselect"
    ]
}
```

See [`src/netselect/README.md`](src/netselect/README.md) for options and behaviour, including upgrading from 1.x.

## Development

```
src/netselect/
├── devcontainer-feature.json   options and metadata
├── install.sh                  entrypoint
├── lib.sh                      pure helpers (unit tested)
└── NOTES.md                    appended to the generated README
test/netselect/
├── unit/lib_test.sh            unit tests, no network or Docker needed
├── scenarios.json              scenario tests, one script per scenario
├── _assert.sh                  shared assertions
└── test.sh                     autogenerated-scenario test (default options)
```

Open the repo in its dev container (it includes Docker-in-Docker and the `devcontainer` CLI), then:

```bash
# Lint and unit tests
shellcheck -x src/netselect/*.sh test/netselect/*.sh test/netselect/unit/*.sh
test/netselect/unit/lib_test.sh

# Scenarios that CI runs (explicit mirror, Ubuntu mirror://)
devcontainer features test --features netselect --filter mirror_ --skip-autogenerated .

# netselect-apt scenarios: need outbound ICMP, so local only
devcontainer features test --features netselect --filter netselect_ --skip-autogenerated .
```

## Releasing

Bump `version` in `devcontainer-feature.json` (semver; breaking changes bump the major), merge to `main`, then run the **Release** workflow manually. It publishes to GHCR and opens a PR with regenerated docs.
